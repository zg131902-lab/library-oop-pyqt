# Библиотека (PyQt5)

Проект по ООП: учёт книг и читателей, выдача и возврат книг.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Тесты: `python -m unittest`

## Отчёт

При закрытии программы в `report.txt` сохраняется сеанс работы:

```
+-----------------------------------------------------+
| login   | time_in             | time_out            |
|---------|---------------------|---------------------|
| student | 14.10.2026 10:00:00 | 14.10.2026 10:05:00 |
+-----------------------------------------------------+
```

## Структура

- `models/` — классы книги, читателя, выдачи и сеанса
- `structures/` — `MyMap`, своя замена `dict`
- `services/` — логика библиотеки и запись отчёта
- `ui/` — окна и виджеты
